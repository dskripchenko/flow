# Редактор

```vue
<script setup lang="ts">
import { ref } from 'vue'
import { FlowEditor, type ChangeEvent } from '@dskripchenko/flow/vue'
import { fromMermaid } from '@dskripchenko/flow/mermaid'

const graph = ref(initial)
function onChange(e: ChangeEvent) {
  // e.command — что изменилось, в виде команды на корне модели
  // e.local   — то же на уровне, где сделано, с путём подпроцесса
  // e.source  — 'edit' | 'undo' | 'redo'
}
</script>

<template>
  <FlowEditor v-model="graph" :mermaid="fromMermaid" style="height: 720px" @change="onChange" />
</template>
```

## Что может пользователь

- **Добавлять** — перетащить тип из панели элементов на холст или нажать на
  него (элемент появится в центре вида); двойной клик по фону добавляет
  state; пункт «Добавить сюда» в контекстном меню.
- **Соединять** — при наведении на узел по его сторонам (или на его портах)
  появляются ручки. Тяните от одной к другому узлу; линия прилипает к
  ближайшей ручке в пределах досягаемости, а новый переход выделяется, чтобы
  сразу дать ему подпись. С клавиатуры — «Добавить переход к…» в свойствах
  узла.
- **Переподключать / отсоединять** — выделите переход и перетащите одну из
  его концевых ручек на другой узел; отпустите на пустом месте, чтобы удалить
  переход.
- **Перемещать** — перетаскиванием; захваченный узел прилипает к сетке
  (кнопка-магнит выключает привязку). Стрелки сдвигают выделение на шаг сетки
  (с Shift — на пять).
- **Выделять** — кликом; Shift/Ctrl/⌘-клик добавляет к выделению;
  Shift-перетаскивание по фону рисует рамку выделения; Ctrl/⌘+A выделяет всё.
- **Упорядочивать** — выравнивание (по левому краю, центру, правому краю,
  верху, середине, низу) и равномерное распределение из панели свойств или
  контекстного меню; «Авто-раскладка» раскладывает всё заново (один шаг
  отмены).
- **Свойства** — подпись, описание, тип, группа, enabled, переходы,
  подпроцесс (ссылка или встроенный граф, который можно открыть и
  редактировать), данные строками ключ/значение (значения, похожие на JSON, —
  числа, булевы, массивы — сохраняются как есть). Для перехода: подпись,
  условие, вид, enabled. Без выделения: заголовок графа и направление
  раскладки.
- **Подпроцессы** — откройте встроенный подпроцесс (маркер, двойной клик или
  свойства) и редактируйте его на месте; хлебные крошки ведут обратно.
  Изменения приходят хосту как `updateNode` узла подпроцесса на корне.
- **Проверять** — вкладка «Проблемы» перечисляет ошибки и предупреждения;
  элементы с проблемами помечены маркером; нажатие на проблему выделяет её
  элемент и показывает его.
- **Импорт / экспорт** — меню «JSON / Mermaid»: экспорт модели в JSON-файл,
  импорт JSON, импорт Mermaid `stateDiagram-v2` / `flowchart` (со свойством
  `mermaid`). Импорт можно отменить.

## Горячие клавиши

| Клавиши | |
|---|---|
| Ctrl/⌘ + Z | отменить |
| Ctrl/⌘ + Shift + Z, Ctrl + Y | повторить |
| Delete, Backspace | удалить выделенное (переходы удалённых узлов уходят тоже) |
| Ctrl/⌘ + C / X / V | копировать / вырезать / вставить (вставленные копии получают новые идентификаторы) |
| Ctrl/⌘ + D | дублировать |
| Ctrl/⌘ + A | выделить всё |
| Стрелки (Shift) | сдвинуть |
| Enter | выделить элемент в фокусе и редактировать его подпись |
| Escape | снять выделение, затем выйти из подпроцесса |
| Space + перетаскивание | сдвиг вида |

Пока вы печатаете в поле, горячие клавиши не срабатывают.

## Свойства

| Свойство | Тип | По умолчанию | |
|---|---|---|---|
| `modelValue` | `Graph` | — | `v-model` |
| `registry` | `NodeTypeRegistry` | встроенные | типы; `locked: true` делает тип только для чтения |
| `palette` | `string[]` | все типы | какие типы предлагает панель элементов и в каком порядке |
| `readonly` | `boolean` | `false` | только просмотр |
| `snapGrid` | `number` | `20` | `0` выключает привязку |
| `direction`, `routing` | | | как во FlowView |
| `nodeRenderers`, `nodeIcons` | | | как во FlowView |
| `mermaid` | `(source) => Graph` | — | включает «Импорт Mermaid»: передайте `fromMermaid` |
| `locale`, `labels` | | `'en'` | |
| `minimap` | `boolean` | `false` | |
| `exportName` | `string` | `'process.json'` | имя экспортируемого файла |
| `toastProvider` | `boolean` | `true` | |

События: `update:modelValue`, `change` (`ChangeEvent`), `select` (идентификаторы),
`validate` (проблемы, при каждом изменении), `export` (текст JSON).
Слоты: `toolbar` (дополнительное содержимое панели инструментов), `properties` (`{ selection, graph, path }`).
Доступно снаружи: `undo()`, `redo()`, `autoLayout()`, `fit()`, `select(ids)`, `history`, `issues`.

На узких экранах (уже 760 px) панели элементов и свойств сворачиваются в
выдвижные панели, которые открываются с панели инструментов; на тач-экранах
долгое нажатие открывает контекстное меню.

Первая правка графа, разложенного автоматически, закрепляет каждый узел там,
где он нарисован (в том же шаге отмены), поэтому ничего не прыгает.

## Команды и история (ядро)

Каждое изменение — это `Command`, которую применяет чистая функция: хост
может воспроизвести её, записать в лог или отправить вместо всей модели:

```ts
import { applyCommand, History, describeCommand } from '@dskripchenko/flow'

type Command =
  | { type: 'addNodes'; nodes; edges? }
  | { type: 'removeElements'; ids }            // узлы, переходы, группы; переходы удалённых узлов уходят тоже
  | { type: 'updateNode' | 'updateEdge' | 'updateGroup'; id; patch } // null удаляет поле
  | { type: 'moveNodes'; moves: { id, position }[] }
  | { type: 'addEdge'; edge }
  | { type: 'setEnabled'; kind: 'node' | 'edge'; id; enabled }
  | { type: 'addGroup'; group }
  | { type: 'updateMeta'; patch }
  | { type: 'replace'; graph }
  | { type: 'batch'; commands }

const history = new History(graph, { limit: 200, mergeWindowMs: 800 })
history.execute({ type: 'updateNode', id: 'a', patch: { label: 'Paid' } }, 'label:a') // одинаковый ключ подряд — слияние
history.undo()
history.redo()
```

Вспомогательные функции: `copyFragment` / `pasteFragment` (новые
идентификаторы, только внутренние переходы), `alignNodes`, `distributeNodes`,
`layoutCommand(layoutGraph(g, { ignorePositions: true }))`,
`nextId(graph, prefix)`, `snap(point, grid)`.
